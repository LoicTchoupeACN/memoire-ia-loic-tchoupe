# Travaux

Espace de travail libre : exercices, prototypes, apprentissage de notions (modèles de taux, outils, etc.). Tout ce qui est ici n'est **pas forcément destiné au mémoire** — certains fichiers y entreront, d'autres resteront de l'entraînement.

Pour s'y retrouver, marque le statut de chaque travail en haut du fichier (ou dans son nom) :
- `[MEMOIRE]` — ce travail nourrit directement le mémoire (résultat, méthode, figure...)
- `[EXPLO]` — apprentissage / exploration, pas destiné au mémoire tel quel, mais peut inspirer une idée (→ à reporter dans `plan_memoire.md` si c'est le cas)
